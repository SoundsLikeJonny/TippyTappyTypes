# TippyTappyTypes

<img width="3840" height="2160" alt="IMG_1024" src="https://github.com/user-attachments/assets/410298d8-7b84-49cb-9a23-673cbe4da624" />


This little typing test can stay open on the side or corner of your screen for a quick typing test while you're working on other things.

Minimal in design, with some stats while you type and when you're done.

<img width="634" height="117" alt="image" src="https://github.com/user-attachments/assets/23bb329b-f18a-45c3-95dd-ae964124657c" />



<img width="640" height="360" alt="BottomRight" src="https://github.com/user-attachments/assets/73d27a02-4b57-4148-8abe-c45ea082489c" />


Adjust the opacity to suit what's on your screen using Control + Up/Down.

Move the position on the screen using Alt + LeftMouseDrag.

<img width="640" height="360" alt="Move-and-Opacity (1)" src="https://github.com/user-attachments/assets/4f7d1a60-890e-4d72-850b-de9ca01ed7ae" />
